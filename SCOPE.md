# SCOPE — v1

**v1 — це компактний HUD у куті екрана, який по хоткею або при зміні треку показує поточний трек із SMTC і дозволяє play/pause/next/previous.**

Список закритий. Дата релізу: `____.____.2026` (вписати конкретне число, не «через 4–6 тижнів»).

---

## Входить

- [x] читання метаданих із SMTC (назва, виконавець, альбом, обкладинка, прогрес)
- [x] play / pause / next / previous — хоткеями і мишею
- [x] показ по хоткею: toggle або hold-to-peek
- [x] пасивний показ на N секунд при зміні треку
- [x] вибір джерела: автоматично або закріплений застосунок
- [x] шість пунктів налаштувань, усе застосовується на льоту
- [x] іконка в треї
- [x] автозапуск з Windows

## Не входить

- будь-яке відтворення звуку власними силами
- бібліотека, плейлисти, черга, пошук
- вибір конкретного треку
- візуалізація, мікшер, таймери, нотатки, погода
- теми оформлення
- будь-яка друга функція

---

## Правило

Кожна нова ідея їде в `IDEAS.md`, не в код. Не встиг до дати — ріжеться
функціонал зі списку вище, дата не переноситься.

Продукт має рівно одну перевагу над Game Bar і оверлеєм NVIDIA: він миттєвий,
легкий і робить одну річ. Ця перевага зникає в момент появи другої функції.
